# Сборка
Компилируется через **webpack** из node.js. Требуемые библиотеки: 
1. "webpack": "^5.104.1"
2. "webpack-cli": "^6.0.1"

Предварительно стоит поставить только **webpack**, остальные библиотеки скачаются в момент компиляции. \\
Команда для компиляции: 
```
npx webpack
```


# Файлы и папки
**src** - исходный код плагина, из которого компилируются файлы **code.js** и **index.html**, нужные для работы плагина.
(Правила компиляции задекларированы в **webpack.config.cjs**)
1. **code.js** - backend плагина
2. **ui.js** - js код для frontend плагина и работы gui
3. **ui.html** - gui плагина
4. **slides.js** - вспомогательный файл с функциями для создания/изменения/выгрузки слайдов
5. **utils.js** - вспомогательный файл с функциями для работы с состоянием плагина и для загрузки нужных ассетов
